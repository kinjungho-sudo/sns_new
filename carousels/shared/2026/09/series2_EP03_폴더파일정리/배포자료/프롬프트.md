# 폴더/파일 정리 — 한번에 완성하는 프롬프트

아래 프롬프트를 복사해, 정리하고 싶은 폴더의 파일 목록(또는 파일들)을 함께 올리세요.
Claude 또는 ChatGPT의 파일 기능이면 됩니다. (추가 계정·설치 불필요)

```
첨부한 폴더의 파일들을 정리해줘. 아래 규칙을 지켜.

1. 내가 쓰는 파일명 규칙은 이거야 — [여기에 규칙 3줄 정도 적기. 예: 분기자료=2024_Q3_매출, 날짜문서=2024-09-10_회의, 양식=제안서_양식]. 이 규칙대로 파일명을 바꿔줘.
2. 바꾼 뒤에는 아래 폴더로 분류해줘: 01_보고서 / 02_계획 / 03_양식 / 04_증빙 / 90_과거자료 / 99_검토필요.
3. 먼저 "어떤 파일을 어떤 이름으로 바꾸고 어느 폴더에 넣을지" 계획을 표로 보여주고 멈춰. 내가 "승인"이라고 하기 전에는 실제로 바꾸지 마.
4. 이름 규칙이 애매하거나 중복·정체불명인 파일은 지우지 말고 99_검토필요로 보내고, 판단이 어려운 건 "확인 필요"로 표시해.
5. 원본 파일을 삭제하거나 덮어쓰지 마. (이동·복사만, 원본 보존)
```

## 전제조건
- Claude 또는 ChatGPT의 파일 업로드/파일 기능. 무료 여부는 사용하는 도구·플랜에 따라 다를 수 있습니다.

## 자주 막히는 곳
- **AI가 승인 없이 바로 실행하려 할 때**: "계획을 표로 먼저 보여주고 멈춰"를 프롬프트에 넣었는지 확인. 빠졌으면 "실행하지 말고 계획 표부터"라고 다시 요청.
- **애매한 파일 처리**: 삭제 대신 99_검토필요로 가는지 결과에서 확인. 원본은 절대 삭제되지 않아야 합니다.
- **규칙이 막연할 때**: 규칙 3줄을 구체 예시(실제 파일명 형태)로 주면 정확도가 올라갑니다.
