# 분기별 매출 통합 — 한번에 완성하는 프롬프트

아래 프롬프트를 복사해, 합칠 매출 엑셀 파일들을 함께 올리세요.
Claude 또는 ChatGPT의 파일 기능이면 됩니다. (추가 계정·설치 불필요)

```
첨부한 매출 엑셀 파일들을 하나로 합쳐줘. 아래 규칙을 지켜.

1. 바로 합치지 말고, 먼저 물어봐 — 어떤 열을 기준으로 합칠지(거래번호/날짜), 중복 거래는 어떻게 처리할지, 요약은 분기·제품·지역 중 무엇으로 낼지. 내가 답할 때까지 통합을 시작하지 마.
2. 원본 파일은 절대 수정하지 마. 통합 결과는 새 파일 하나로만 만들어.
3. 통합이 끝나면 검증 표를 반드시 같이 보여줘 — 원본 파일별 "건수 / 매출 합계 / 거래번호 중복·누락"을 표로 원본과 대조해줘.
4. 원본 합계와 통합 결과가 다르면, 어느 파일·어느 항목에서 얼마나 차이 나는지 표로 보고해줘. 임의로 숫자를 맞추지 마.
5. 결과물(통합 시트 + 요약 + 검증 표)만 출력하고, 인사말이나 설명은 붙이지 마.
```

## 전제조건
- 합칠 매출 엑셀 파일들 + Claude 또는 ChatGPT의 파일 기능.

## 자주 막히는 곳
- **합계가 안 맞을 때**: 검증 표에서 어느 파일이 차이 나는지 먼저 확인. 대개 중복 거래번호나 헤더 행 포함 때문입니다.
- **AI가 바로 합쳐버릴 때**: 1번 규칙(먼저 기준 확인)이 프롬프트에 있는지 확인. 없으면 "합치기 전에 기준부터 물어봐"라고 다시 요청.
- **눈으로 검산하지 마세요**: 4번 검증 표로 대조하는 게 훨씬 빠르고 정확합니다.
