# EP07 · 출장 숙소 예약, 결제 직전까지 AI에게 맡기기

## 준비
- 브라우저를 직접 조작하는 AI 기능이 필요합니다: Claude in Chrome(크롬 확장, Claude 유료 플랜) 또는 ChatGPT 에이전트 모드(유료).
- 일반 채팅창에서는 실제 사이트 검색 대신 검색 계획과 체크리스트까지만 받을 수 있어요.
- 연습용 조건은 `EP07_출장_시나리오.xlsx`에 있어요. 내 출장 조건으로 바꿔 쓰면 됩니다.

## 순서
1. 크롬에서 Claude in Chrome(또는 에이전트 모드)을 켠다.
2. 아래 프롬프트의 [조건]을 내 출장에 맞게 고쳐 붙여넣는다.
3. 비교표에서 숙소를 고르면, AI가 객실 선택 화면까지 가서 멈춘다. 예약자 정보 입력과 결제는 직접 한다.

## 한번에 완성하는 프롬프트
```
아래 조건으로 출장 숙소를 알아보고, 예약 직전까지 진행해줘.

[조건]
- 지역: 부산 해운대 (미팅 장소 인근)
- 일정: 2026-10-14 체크인 ~ 2026-10-16 체크아웃 (2박), 성인 1명, 객실 1개
- 예산: 1박 12만원 이하 (세금·수수료 포함 총액 기준, 2박 합계 24만원 이하)
- 숙소: 비즈니스호텔, 평점 4.0 이상(5점 기준), 조식 포함 선호
- 사이트: 네이버 예약, 야놀자, 부킹닷컴 중 접속되는 곳 하나

[진행]
1. 사이트에서 지역·날짜·인원을 넣어 검색해줘.
2. 조건에 맞는 숙소 3곳을 표로 비교해줘 — 숙소명 / 2박 총액(세금 포함) / 평점 / 조식 / 위치.
   - 사이트 평점이 10점 척도면 8.0 이상으로 환산해서 판단하고, 환산했다고 표에 적어줘.
   - 세금이 별도로 붙는 요금은 포함한 총액으로 비교해줘.
   - 광고 숙소인지와 상관없이 조건으로만 골라줘. 로그인해야 보이는 회원가는 참고로만 따로 적어줘.
3. 내가 하나를 고르면 그 숙소의 날짜·인원·객실 유형을 맞게 선택해줘.
4. 예약자 정보 입력이나 결제 화면으로 넘어가기 직전에 멈추고, 선택한 내용(숙소·객실·총액)을 정리해서 나에게 확인을 요청해줘.

[지킬 것]
- 결제, 예약 확정, 개인정보·카드 정보 입력은 절대 하지 마. 내가 직접 한다.
- 화면의 가격·조건이 위 예산과 다르면 먼저 알려줘.
- 조건에 맞는 숙소가 3곳이 안 되면 억지로 채우지 말고, 어떤 조건을 완화하면 되는지 제안해줘.
```

## 자주 막히는 곳
- 평점 척도가 사이트마다 달라요(5점/10점). 프롬프트에 환산 기준을 넣어 두세요.
- 표시 요금에 세금이 빠진 곳이 있어요. "세금 포함 총액" 기준을 꼭 적으세요.
- 검색 상위에 광고 숙소가 섞여요. "조건으로만 골라줘"를 넣으세요.
- 날짜마다 재고·가격이 바뀌어요. 결과가 매번 달라도 정상입니다.
