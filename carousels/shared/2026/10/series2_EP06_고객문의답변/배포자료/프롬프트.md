# 고객 문의 답변 초안 — 복붙 프롬프트

회사 응대 기준과 고객 문의를 읽혀, **고객 발송용 답변 초안**과 **내부 확인사항**을 나눠서 만드는 프롬프트입니다.
핵심은 하나 — 기준으로 확정할 수 있는 것만 답하고, 할인·미확정 일정처럼 **확정 못 하는 건 약속하지 말고 내부 확인으로 빼게** 하는 것입니다.

## 준비물
- 회사 응대 기준 문서 1개 (가격·인원·지역·준비물·제공 범위·승인 규칙)
- 고객 문의 메일 (아래 예시 파일로 연습 가능)

> [참고] ChatGPT 무료 플랜은 파일 업로드가 하루 3개 수준이고 계정·시간대에 따라 더 낮아질 수 있습니다.
> 이 연습은 파일이 3개(기준 + 문의 2건)라, 한 대화에 여러 파일을 올릴 수 있는 Claude 무료 또는 유료 플랜이면 수월합니다.

---

## 1단계 — 답변 초안 만들기 (복붙)

```
첨부한 회사 응대 기준과 고객 문의를 읽고, 고객에게 보낼 답변 초안을 작성해줘.

규칙:
1) 고객이 묻거나 요청한 항목을 빠짐없이 다룬다.
2) 회사 기준으로 확정할 수 있는 것만 답한다.
3) 기준으로 확정하려면 승인·추가 확인이 필요한 항목(할인, 미확정 일정, 기본 범위 밖 제공, 기준 인원 초과 등)은
   고객에게 가능하다고 약속하지 말고 "내부 확인사항"으로 따로 뺀다.
4) 견적·일정 검토에 필요한데 문의에 없는 정보만 고객에게 묻는다. 고객이 이미 알려준 정보는 다시 묻지 않는다.
5) 기준 문서에 없는 수치·조건·약속을 지어내지 않는다. 불명확하면 '확인 필요'라고 표시한다.
6) 어조는 정중하고 간결한 존댓말, 과장된 홍보 문구는 넣지 않는다.
   순서는 인사 → 질문별 답변 → 필요한 확인 사항 → 맺음말.

출력 형식:
[고객 발송용]
제목: ...
본문: ...
[내부 확인사항]   (고객에게 보내지 않음)
- 승인·확인이 필요한 항목과 이유

초안은 담당자가 검토하고 실제로 발송한다는 전제로 작성해줘.
```

## 2단계 — 반복용 'Skill'로 저장하기 (선택)

```
방금 사용한 답변 작성 방법을 반복해서 쓸 수 있게 '고객 문의 답변' 규칙으로 저장해줘.
이번 고객의 이름·날짜·요청 내용은 고정 규칙으로 넣지 말고, 어떤 문의에도 동작하도록 일반화해줘.
```
※ Claude Skills·프로젝트 지침·커스텀 GPT 지침처럼 반복 지침을 저장하는 기능이 있으면 그대로 등록하고,
없으면 위 1단계 규칙을 "다음 문의부터 이 규칙으로 답해줘"라고 붙여넣어 똑같이 쓰면 됩니다.

## 3단계 — 새 문의에 재사용하기

```
저장한 '고객 문의 답변' 규칙으로, 첨부한 새 고객 문의의 답변 초안을 작성해줘.
```

---

## 자주 막히는 곳
- **AI가 덜컥 약속하는 문제**: "할인 가능합니다", "그 날짜 됩니다"처럼 기준에 없는 걸 단정하기 쉽습니다.
  규칙 3번(확정 못 하면 내부 확인으로)을 반드시 넣으세요.
- **원본에 없는 값 지어내기**: 모르면 '확인 필요'로 남기게 하세요(규칙 5).
- **사람 검토 필수**: AI 출력은 '초안'입니다. 담당자가 확인한 뒤 보냅니다.

## 연습용 예시 파일
- `01_회사_응대기준.txt` — 회사 기준
- `02_고객문의_예시A.txt` — 기준 안에서 확정되는 문의(18명·서울)
- `03_고객문의_예시B.txt` — 할인·원본 요청 등 확정 못 하는 항목이 섞인 문의(28명)

> 모두 가공한 예시이며 실제 회사·인물 정보가 아닙니다.
