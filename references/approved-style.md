# Approved Scene Overlay Carousel Style

Use this as the compact handoff note for future SNS carousel sessions.

- Default skill: `instagram-carousel-scene-overlay`.
- Series: `AI와 함께하는 1인 창업 도전기`.
- Brand defaults: `CoMindWorks`, `comindworks`, no subtitle, no profile photo, teal accent, dark style.
- Output contract: editable HTML, local assets, `1080x1350` PNGs, contact sheet, PNG-only ZIP, caption/copy notes.
- Layout: full-bleed story-specific scene, lower black gradient/progressive blur, restrained Korean typography, one muted-orange rounded underline, small page counter.
- Scene strategy: each card should communicate its point visually. Use workspaces, UI, documents, evidence, timelines, comparison scenes, or emotional moments.
- Avoid: repeated explanatory boxes, generic icon grids, robots, neon cyberpunk, decorative charts, unsupported claims, and victory-lap language.
- Public wording: avoid unnecessary real names/company/place references; anonymize as needed.
- Verification: check dimensions, PNG count, ZIP entries, contact sheet, final wording scan, and local assets.
