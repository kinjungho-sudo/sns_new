# 시리즈 2 캐러셀 (AI 업무 자동화)

## 목적 (왜 만드는가)
- 브랜드 퍼널: **'이것 하면 → 김정호/CoMindWorks/Parro'**가 떠오르게 만든다.
- 포지셔닝: **"누구나 끝까지 따라올 수 있는 AI 교육을 하는 사람"** (타겟 = 1인창업가가 아니라 **직장인**).
- 전환 퍼널: 결과물을 먼저 보여줌 → 댓글/DM으로 프롬프트·양식 무료 배포 → **개인강의(지금)·기업교육(이후)·Parro(무료 MVP)**로 유입.
- 톤앤매너: 친근·쉽게·진짜 따라할 수 있게. 과장·허세 금지.

## 주로 만드는 콘텐츠
- **시리즈 2 'AI 업무 자동화' — 정적 캐러셀(7장), 2일 주기 게시.** 직장인이 실제 업무(회의록·지출·메일·엑셀·보고서 등)을 AI로 자동화하는 법을 Before→After로 보여준다. (미리 여러 편 만들어두고 2일에 한 편씩 순차 게시)
- 각 편은 프롬프트/스킬/예약실행/프로젝트/브라우저자동화 중 하나의 '방식'으로 해결.
- 구분: 시리즈 1 '1인창업 도전기'(서사·앵버 시네마, 별도 채널/세션)과 구분. 이 스킬은 **시리즈 2 전용**.

## 기획 프로세스 (제작 전 반드시)
1. **주제 선정** — `series2_AI자동화/backlog.csv`에서 꼼다. 우선순위: ①가벼운 것(입력 적고 단계 짧고 실패율 낮음) ②동작확실성 높은 것 ③시각임팩트 큰 것 초반 배치 ④강의로 이어지는 주제(견적서 등)는 신뢰 쌓인 뒤. 밀리면 못 올리므로 수십 개 미리 쌓아두고 꺼낸다.
2. **검증 게이트** — 선택 즉시 실제로 돌려보고(아래 5개) 통과해야 제작. 안 되면 보류.
3. **앵·서사 잡기** — 직장인이 "내 얘기다" 할 실제 고통(Before) → 30초 결과물(After). 훅은 기존 방식의 허마함을 직격.
4. **카피 기획** — 7장 슬롯에 메시지 배분(아래 3장 구조). 슬라이드당 30단어 이하, 포커스 1개.
5. **결과물 프레임 선택** — 주제를 5프레임(문서/대화/화면/표/설정) 중 하나에 매핑(B방식).
6. **제작→저장→백로그 갱신→배포자료→게시** (아래 빌드 워크플로우).

## 0. 절대 원칙
- **동작하는 것만 올린다.** 아래 검증 게이트를 통과하지 못하면 제작하지 않는다.
- 카드에 **실명 금지**(역할명으로: 팀장·담당자 등). 예외: 사용자가 준 자기 양식의 샘플명은 그대로 가능.
- 푸터는 **CoMindworks만** (`Co`+러스트`Mind`+`works`). @핸들·개인명 넣지 않는다.
- **Parro 캐릭터 등장 금지** (카드에서 뺀다).
- 프롬프트/양식/소스는 **카드에 넣지 않고** 배포자료로만 전달.

## 1. 검증 게이트 (5개 모두 통과해야 제작)
1. 처음부터 끝까지 실제로 돌려 결과물까지 완주했는가
2. 같은 입력이면 누구나 같은 결과가 재현되는가
3. 전제조건(계정·플랜·연동)이 명확한가 → 카드/배포자료에 명시
4. 자주 막히는 곳과 해결법을 아는가 → 배포자료에 포함
5. 결과물이 시각적으로 '오' 소리 나거나 명백한 시간절약이 보이는가

## 2. 결과물 프레이밍 (B방식 = 진짜 결과물을 브랜드로 깔끔하게)
생 스크린샷도 가짜 UI도 아니다. **실제 출력을 직접 크리스프 재현**한다.
주제를 아래 5프레임 중 하나에 매핑:

| 형태 | 적용 |
|---|---|
| 문서형(회의록·견적서·보고서) | 양식을 HTML로 크리스프 재현(빈 양식+채운 양식) |
| 대화형(메일·번역·프롬프트) | 실제 AI 대화를 브랜드 말풍선으로 재현 + 핵심 1줄 강조 |
| 화면형(일정·차트·대시보드) | 실제 출력을 브라우저/폰 프레임+크림 배경+그림자 |
| 표·리스트형(엑셀·리서치) | 실제 표를 크리스프 재현 |
| 설정형(스킬·예약·n8n) | 실제 워크플로우를 카드로 정돈 + 핵심 노드 강조 |

프레이밍 공통: 여백 정리 → 핵심만 타이트 → 부드러운 배경 → 그림자 → 콜아웃 1개.

## 3. 7장 구조 (Before→After)
1. 표지(Bold Claim): 훅 + 결과물 티저 + 입력칩 흐름(텍스트·사진·녹취 → 결과물) + '밀어서 보기 →'
2. Before: 문제 상황(공감) — 지저분한 원본
3. 핵심: '우리 회사 양식/평소 방식 그대로 넣으세요' — 빈 결과물틀
4. After: 30초 뒤 완성된 결과물
5. 딱 3단계: 붙여넣기 → 입력 던지기 → 결과 받기
6. 3줄 요약 + '자주 막히는 곳' 노트박스
7. CTA: 댓글 키워드 → 양식+프롬프트 배포 / 팔로우 → 다음 편 받기
규칙: 슬라이드당 30단어 이하, 포커스 1개, 고대비.

## 4. 디자인 토큰
- 배경 크림 `#ECE6D8` + 도트 텍스처(radial-gradient 26px)
- paper `#FBF8F1`, ink `#2A241F`, rust `#C0592F`, rust2 `#E4B9A3`, rsoft `#F0DCCF`, muted `#9A8F82`
- 폰트 **A2Z**(9웨이트, 100~900). 헤드라인 900/800, 본문 500/400. 헤드라인에 rust 하이라이트 밑줄.
- 카드 1080×1350, 상단 러스트 pill 태그(예 'AI 업무 자동화')+'EP.NN·주제', 하단 CoMindworks+'NN/7'.

## 5. 빌드 워크플로우 (연결 폴더 D:\\project\\sns_claude)
1. 재료 확보: 실제 Before(원본)·After(결과물). 필요시 ChatGPT로 손글씨/노트 사진 등 생성.
2. 결과물틀을 `_system/templates/meeting_template.py` 방식으로 HTML→PNG 렌더(빈/채움).
3. 카드는 `_system/templates/carousel_build7.py` + `font.css` + `_system/fonts`(A2Z) 재사용.
   - Playwright chromium, `device_scale_factor=2`, `.card` 요소 스크린샷.
   - 이미지 에셋은 base64 인라인. 폰트는 @font-face 상대경.
4. PDF는 `img2pdf`로 카드 7장 결합(PIL의 JPEG-PDF 버그 회피).
5. 저장: `series2_AI자동화/EPNN_주제/` 아래 `카드/`(7장)·PDF·`캡션.txt`·`배포자료/`(양식+프롬프트). 재사용 에셋은 `_system/style|templates`.
6. 백로그(`series2_AI자동화/backlog.csv`) 상태 갱신: 미검증→검증완료→제작완료·게시대기→게시.

## 6. 배포자료 (댓글/DM 자동발송용, 카드엔 미포함)
- `배포자료/<실제 원본 양식 파일 그대로>`: 사용자가 준 원본 양식을 원본 형식 그대로 넣는다(예: `.xlsx`·`.docx` 등). 형식을 `.md` 등으로 임의 재구성하지 말 것 — 상위 `AGENTS.md`의 "실제 원본 파일 그대로" 규칙 준수. 원본이 없으면 만들지 말고 사용자에게 요청.
- `배포자료/프롬프트.md`: 복붙용 지시문(원칙+전제조건+자주 막히는 곳)
- `캡션.txt`: 훅→공감→핵심→CTA(댓글 키워드)→팔로우. @핸들 없음. 해시태그 10개 내외.
- 양식·프롬프트를 Drive/Notion 공개링크화 → 댓글→DM 자동화(별도 세션 구축)에서 링크 전송.

## 7. 검수 체크
- 컨택트시트(7장 축소)로 겹침·가독성·톤 일관 확인 후 전달.
- 확정 전 실물 결과물이 검증 게이트를 통과했는지 재확인.
