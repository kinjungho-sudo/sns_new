## Before → After
- Before(문제 상황): 이름 규칙 없이 뒤섞인 파일들(날짜·양식·분기자료 구분 없음)이 한 폴더에 쌓여 있음
- After(30초 결과물): 규칙대로 이름이 바뀌고, 폴더별(보고서/계획/양식/증빙/과거자료/검토필요)로 자동 분류 완료

## 7장 카피 초안 (30단어 이하 / 슬라이드, 포커스 1개)
1. 표지(Bold Claim): "폴더 정리, AI한테 시켰더니 3분 컷" + 입력칩(뒤섞인 파일들 → 정리된 폴더) + "밀어서 보기 →"
2. Before: 파일명 제각각, 분기자료·양식·날짜문서가 한 폴더에 뒤섞인 화면
3. 핵심: "내가 쓰는 파일명 규칙만 알려주세요" — 규칙 3줄(분기자료/날짜문서/양식) 제시
4. After: 규칙대로 이름 바뀐 파일 목록 + 6개 폴더(01~04, 90, 99)로 깔끔히 분류된 화면
5. 3단계: 프롬프트 붙여넣기 → 계획(표) 확인 → "승인" 한마디로 실행
6. 3줄 요약 + 자주 막히는 곳: "애매한 파일은 삭제 대신 99_검토필요로 — 절대 임의 삭제 안 함"
7. CTA: 댓글에 "폴더정리" 남기면 프롬프트 DM / 팔로우하면 매일 1편

## 배포자료 요구사항
- 실제 원본 파일: 없음(파일이 아니라 프롬프트 자체가 자료) — `실습안내.txt`, `프롬프트.txt` 원문 구조를 그대로 반영
- 완성형 단일 프롬프트 조건:
  - 1단계(파일명 정리)와 2단계(폴더 분류)를 하나의 프롬프트로 통합하되, "계획을 먼저 표로 보여주고 승인 후 실행" 흐름은 반드시 유지 (자동 실행 금지 — 사용자 승인 필수 명시)
  - 애매하거나 중복된 파일은 삭제하지 말고 "99_검토필요"로 이동하도록 명시
  - 판단 어려운 파일명은 "확인 필요"로 표시하도록 명시
  - 원본 삭제·덮어쓰기 절대 금지 문구 포함
