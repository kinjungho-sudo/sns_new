## Before → After
- Before: 출장 숙소 하나 잡으려고 예약 사이트를 돌며 날짜·인원 넣고, 예산·평점·조식을 하나씩 비교하는 반복.
- After: 조건을 한 번 적어 주면, 브라우저를 직접 조작하는 AI가 검색 → 조건 맞는 후보 3곳 비교표 → 고른 숙소 객실 선택 화면까지 진행하고 **예약자 정보·결제 직전에 멈춰 확인을 요청**. 결제는 사람이.
- 시간 수치 주장 없음(측정 기록 없음).

## 핵심 메시지
손이 많이 가는 검색·비교는 AI, 돈 쓰는 결정은 사람.

## 실행 요건 (과장 금지)
실제 사이트 검색·이동은 **브라우저를 직접 조작하는 AI 기능**이 필요 — Claude in Chrome(크롬 확장, Claude 유료 플랜) 또는 ChatGPT 에이전트 모드(유료). 일반 채팅만으로는 검색 계획·체크리스트까지만.

## 7장 카피 (카드 = 블로그용)
1. 표지: "출장 숙소, 결제 직전까지 AI가 알아봐 줍니다" + 입력칩(출장 조건 → 후보 3곳 비교 → 예약 직전 정지) + 밀어서 보기 →
2. BEFORE: 예약 사이트 탭 여러 개, 날짜·예산·평점을 하나씩 대조하는 반복
3. 핵심: "찾아줘"가 아니라 조건(지역·날짜·예산·평점·조식)과 **멈출 지점**을 같이 정해 주기
4. AFTER: 조건 맞는 후보 3곳 비교표(가격·평점·조식·위치) + "객실 선택 화면에서 멈췄습니다. 결제는 직접 확인해 주세요"
5. 딱 3단계: 브라우저 AI 켜기 → 조건+정지 규칙 붙여넣기 → 비교표 보고 고르면 예약 직전까지
6. 3줄 요약 + 자주 막히는 곳: 평점 척도(5점/10점)·세금 별도 요금·광고 상단 노출 → 프롬프트에 기준 명시
7. CTA: 댓글에 '자료' (인스타) / 블로그는 본문 자료실 링크

## 숏폼 대본 (나레이션, 약 35초)
1. 출장 숙소 하나 잡는데, 예약 사이트를 몇 개나 열어 보셨나요?
2. 날짜 넣고, 예산 보고, 평점 보고, 조식까지 하나씩 비교하다 보면 시간이 금방 갑니다.
3. 이제는 조건만 적어 주면, AI가 브라우저를 직접 열어 검색합니다.
4. 예산과 평점에 맞는 숙소 세 곳을 표로 비교해 주고,
5. 고른 숙소의 객실 선택 화면까지 갔다가, 결제 직전에서 멈춥니다.
6. 요령은 하나. 무엇을 찾을지와 함께, 어디서 멈출지를 꼭 정해 주는 겁니다.
7. 검색과 비교는 AI에게, 결제는 내가 직접.
8. (인스타) 조건 프롬프트와 연습용 출장 시나리오는 댓글에 '자료'를 남겨 주세요. / (공용) 고정 댓글에서 자료를 받아 가세요.
